# NexTirupur.in | Tirupur Job Hub

The most trusted digital bridge for Tirupur's Garment Industry.

## 🚀 Project Status: 95% Complete (MVP)

### Feature Checklist

#### 🧵 Job Seeker Experience
- [x] **Simplified Worker Profiles**: Quick setup for tailors/checkers (No resumes).
- [x] **Detailed Staff Profiles**: Digital resume builder + PDF upload.
- [x] **Instant Language Access**: EN/தமிழ்/HI toggle visible on mobile screens.
- [x] **Distance Visibility**: "Near Me" filtering with precision radius slider.
- [x] **Local Benefits UI**: Icons for ESI/EPF, Transport, and "Tea Cash".
- [x] **Payout Schedules**: Clear payment timing (Weekly/Monthly) on all jobs.

#### 🏭 Employer Experience
- [x] **Privacy Protection**: Phone numbers hidden from public view.
- [x] **Candidate Unlocking**: Control over when contact details are shared.
- [x] **Save as Draft**: Save job progress and resume later.
- [x] **Performance Stats**: Track job views and application conversion rates.
- [x] **Manual Closing**: Instantly close listings after hiring.
- [x] **GST Compliance**: 18% GST collection and automated B2B invoicing.

#### 🛡️ Platform Trust & Safety
- [x] **Employer Verification**: Mandatory GST and Factory Gate photo proof.
- [x] **Public Proof**: Verification data is visible to workers for safety.
- [x] **Anti-Fraud Reporting**: Aggregated reporting (One report per account).
- [x] **Trust Badges**: "Member Since" indicators for all users.
- [x] **Auto-Expiry**: 15-day job validity logic.
- [x] **Corporate Legitimacy**: NexTirupur GST/MSME badges on homepage.

#### 📢 Communication & Admin
- [x] **WhatsApp Forwarding**: Rich template sharing for job seekers.
- [x] **Super Admin Panel**: Global moderation and report management.
- [x] **High-Fidelity Logging**: Comprehensive browser console audit groups.
- [x] **Mobile Optimization**: Responsive dashboards for all roles.
